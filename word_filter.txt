# ============================================================================
#  Church AI Translation — word filter
#  Used by BOTH apps (Python and Swift). Edit this file to add or remove words.
#  After editing: restart the Python app; for the Swift app, rebuild it.
#
#  How it works:
#   - Matching ignores capital letters and accents (cabrón = cabron = CABRON).
#   - Only whole words match ("escoger" is NOT affected by "coger").
#   - A * at the end matches any ending:  fuck*  also matches fucking, fucked…
#   - [block]   Never spoken, never shown in captions, never saved.
#               English words show as ••• in the volunteer panel.
#               Spanish words are dropped from the voice and captions.
#               Words here are also blocked inside the translation model itself
#               (Python app), so it chooses a different word instead.
#   - [replace] Swap a risky word for a safe one:   risky => safe
#               Mainly Spain-Spanish words that are vulgar in Latin America.
#   - [allow]   Never filtered, even if they match a [block] pattern.
#               Bible and sermon words like "hell" belong here.
#  Lines starting with # are notes and are ignored.
# ============================================================================
